Start testing an existing game in a minute. `npx keiko init` writes a first test for the engine your project uses and prints a starter `window.__KEIKO__` hook. `game.engine` reads the active scene and the pressable, on-screen objects straight from Phaser 3 or PixiJS 8, with no hook. `await game.tapWhenReady(find)` waits for a button to appear and stop moving before tapping it.
